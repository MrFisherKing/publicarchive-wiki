Filed a routine FOIA request a while back on some early-90s black budget line items, mostly just curious about R&D allocations in that period, nothing specific in mind. Got a partial response back — most of it is exactly what you'd expect, boring line items, mostly redacted per usual exemptions. But one entry caught my eye because of how heavily it's blacked out relative to everything around it. Scanned the relevant page below. Anyone recognize the program name, or seen anything else reference it?

UNCLASSIFIED // FOR OFFICIAL USE ONLY
DEPT. OF DEFENSE — SPECIAL PROGRAMS BUDGET SUMMARY (EXCERPT)
FISCAL YEAR: 1991–1992    PAGE 14 OF       
LINE ITEMPROGRAMALLOCATION
4471-BADV. MATERIALS RESEARCH$1,204,000
4471-CSIGNALS PROCESSING UPGRADE$886,500
4472-A               — SUBPROGRAM "PROJECT SECOND SIGHT"       
4472-B                             
4473-AFACILITIES MAINTENANCE, REGION 4$2,410,900
EXEMPTIONS CITED: (b)(1), (b)(3) —                     
[scan_page14_foia_1991.jpg — image quality reduced from original post]

Line item 4472-A is the one. Every other item on the page has a normal amount of redaction — program name visible, dollar figure visible, maybe a sentence blacked out. This one's got the parent program name redacted AND the dollar figure AND it's the only one with a subprogram name actually left visible, "Project Second Sight," which is a weird thing to leave in if they wanted the rest hidden. Not reading anything into it, just seems like an odd redaction choice and wanted to see if anyone's run into this name before.

Redaction inconsistency like that is honestly really common and usually just means two different reviewers touched the same document, one more cautious than the other. Wouldn't read too much into the name being left in, might've just been an oversight, happens constantly with FOIA processing. Still, never heard the name "Second Sight" attached to anything I've seen, and I've been doing this a long time. If it's real it's a small program, not the kind of thing that shows up in appropriations testimony.
